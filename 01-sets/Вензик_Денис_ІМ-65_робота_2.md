## Завдання  

### 1. Спростити вирази  

1. `A \ (B ∪ C) ∪ (A \ B) ∩ (A \ C)`  
Розберемо `A \ (B ∪ C)`. За правилом тотожністю різниці множин та теоремою де Моргана `A / B = A ∩ B‾` => `A \ (B U C) = A ∩ (B U C)‾ = A ∩ B‾ ∩ C‾`.  
Далі `(A \ B) ∩ (A \ C) = (A ∩ B‾) ∩ (A ∩ C‾) = A ∩ B‾ ∩ C‾`.  
Підставимо в початкове рівняння `(A ∩ B‾ ∩ C‾) ∪ (A ∩ B‾ ∩ C‾)`. За властивістю `X ∪ X = X` маємо `(A ∩ B‾ ∩ C‾) ∪ (A ∩ B‾ ∩ C‾) = A ∩ B‾ ∩ C‾ = A / (B ∪ C)`  
Відповідь: `A \ (B ∪ C)`  

2. `((A \ C) \ (B \ C)) ∩ ((A \ B) \ C) ∪ A ∩ (B ∪ A)`  
Спростимо першу частину  
1. `((A \ C) \ (B \ C)) ∩ ((A \ B) \ C)`. `(A \ C) \ (B \ C) = (A ∩ C‾) ∩ (B U C‾)‾ = A ∩ C‾ ∩ (B‾ ∪ C) = (A ∩ C‾ ∩ B‾) ∪ (A ∩ C‾ ∩ C) = A ∩ B‾ ∩ C‾`  
2. `(A \ B) \ C = (A ∩ B‾) ∩ C‾ = A ∩ B‾ ∩ C‾`  
Спростимо другу частину  
1. `A ∩ (B ∪ A) = A` - За законом поглинання  
Відповідь: `(A ∩ B‾ ∩ C‾) ∪ A = A` - За законом поглинання  

### 2. Що можна сказати про множини A та B, якщо виконується задана рівність?  

1. `A ∸ B = B`  
`A = ∅`  
Пояснення:  
`A ∸ B = (A \ B) ∪ (B \ A)` Для усіх х ∈ А:  
`Ʞ x ∈ B => x ∉ (A \ B) та x ∉ (B \ A)`, отже `x ∉ A ∸ B`, але за умовою `x ∈ B`.  
`Ʞ x ∉ B => x ∈ A \ B ⊆ (A ∸ B)`, отже `A = ∅`.  
2. `A ∸ B = ∅`  
Відповідь: `A = B`  
Об'єднання двох множин порожнє тоді й тільки тоді коли обидві множини порожні:  
`A \ B = A ⊆ B`  
`B \ A = B ⊆ A`  
Отже `A = B`  
3. `A ∸ B = C` (для деякої фіксованої множини `C`; опишіть, що можна сказати про зв'язок `A`, `B` і `C`)  
Відповідь: `A = B ∸ C`, `B = A ∸ C`  
Спростимо рівняння `A ∸ B = C; (A ∸ B) ∸ B = C ∸ B; A ∸ (B ∸ B) = B ∸ C`, за властивістю `X ∸ X = ∅` маємо:  
`A ∸ ∅ = B ∸ C`, за властивістю `X ∸ ∅ = X`. маємо:  
`A = B ∸ C`, або `B = A ∸ C`  
4. `(A \ B) ∸ (B \ A) = ∅`  
Відповідь: `A = B`  
`Ʞ X = (A \ B), Y = (B \ A)`, X та Y не перетинаются.  
Для неперетинних множин `X ∸ Y = X ∪ Y`, отже `X = ∅, Y = ∅`, `A ⊆ B, B ⊆ A => A = B`  
5. `(A ∪ B) ∸ A = B`  
Відповідь: `A ∩ B = ∅`  
`((A ∪ B) \ A) ∪ (A \ (A ∪ B)) = B`, оскільки `(A ∪ B) \ A = B, A \ (A ∪ B) = ∅ => B \ A = B => A ∩ B = ∅`  

### 3. Довести тотожність

Довести, що для будь-яких множин `A` і `B`:  

`A ∪ B = A ∪ (B \ A) = (A \ B) ∪ (A ∩ B) ∪ (B \ A)`,  

і що три множини у правій частині останнього виразу попарно не перетинаються  
(тобто це розбиття `A ∪ B` на три неперетинні частини).  

1. Доведемо, що `A ∪ B = A ∪ (B \ A)`  
`A ∪ (B ∩ A‾) = (A ∪ B) ∩ (A ∪ A‾) = (A ∪ B) ∩ U = A ∪ B`, доведено.  
2. Доведемо, що `A ∪ (B \ A) = (A \ B) ∪ (A ∩ B) ∪ (B \ A)`  
`(A \ B) ∪ (A ∩ B) = (A ∩ B‾) ∪ (A ∩ B) = A ∩ (B‾ ∪ B) = A ∩ U = A`  
Підставимо це вираження для `A‾` назад у ліву частину:  
`A ∪ (B \ A) = (A \ B) ∪ (A ∩ B) ∪ (B \ A)`, доведено.  

3. Доведемо попарне неперетинання трьох множин.  
`Ʞ X = A \ B = A ∩ B‾, Y = A ∩ B, Z = B \ A = B ∩ A‾`  
`X ∩ Y = (A ∩ B‾) ∩ (A ∩ B) = A ∩ (B‾ ∩ B) = A ∩ ∅ = ∅`  
`Y ∩ Z = (A ∩ B) ∩ (B ∩ A‾) = B ∩ (A ∩ A‾) = B ∩ ∅ = ∅`  
`X ∩ Z = (A ∩ B‾) ∩ (B ∩ A‾) = (A ∩ A‾) ∩ (B ∩ B‾) = ∅ ∩ ∅ = ∅`  
Доведено.
