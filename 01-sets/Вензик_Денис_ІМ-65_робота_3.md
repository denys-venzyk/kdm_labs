# Домашнє завдання 3. Множини: рівняння  

**Тема:** Теорія множин  

## Завдання  

Розв'язати рівняння (там, де вказана додаткова умова — врахувати її):  

1. `A ∸ B = B ∸ X`  
Відповідь: `A = X`  
`(A ∸ B) ∸ B = (B ∸ X) ∸ B => A ∸ (B ∸ B) = (B ∸ B) ∸ X => A ∸ ∅ = ∅ ∸ X => A = X`  
2. `A ∪ X = X \ B`  
Відповідь: Якщо `A ∩ B = ∅ => A ⊆ X ⊆ B‾`. Якщо `A ∩ B ≠ ∅` => розв'язків немає.  
`A ∪ X = X ∩ B‾ => (A ∪ X) \ (X ∩ B‾) = ∅ => (A ∪ X) ∩ (X ∩ B‾)‾ = (A ∪ X) ∩ (X‾ ∪ B) = (A ∩ X‾) ∪ (A ∩ B) ∪ (X ∩ X‾) ∪ (X ∩ B) = (A ∩ X‾) ∪ (A ∩ B) ∪ (X ∩ B) => (A ∩ X‾) ∪ (A ∩ B) ∪ (X ∩ B) = ∅ => A ∩ X‾ = A ⊆ X, B ∩ X = X ⊆ B‾` => Якщо `A ∩ B = ∅ => A ⊆ X ⊆ B‾`. Якщо `A ∩ B ≠ ∅` => розв'язків немає.  
3. `C \ B = (A ∪ B) \ X`, `A ⊆ C`
Відповідь: `B ⊆ X ⊆ A ∪ B`.
`C ∩ B‾ = (A ∪ B) ∩ X‾` => Ліва частина складається з елементів С які не містяться в В. Права частина складається з елементів `(A ∪ B)` які не належать Х. Щоб рівняння виконувалося треба щоб обидві частини були рівні між собою, тобто можемо одразу сказати що `B ⊆ X`, але так як нам треба виключити усі елементи Х з множини A ∪ В щоб рівняння виконувалося, то можемо стверджувати що `X ⊆ A ∪ B`, отже розв'язком рівняння буде `B ⊆ X ⊆ A ∪ B`.
4. `X \ A = C \ X`
Відповідь: `C ⊆ X ⊆ A`
`X ∩ A‾ = C ∩ X‾` => Ліва частина складається повністю з елементів множини Х, а права повністю з множини С при цьому жодного елемента множини Х не має, але обидві частині повинні бути рівні, отже зліва усі елементи Х повинні одночасно дорівнювати жодному елементу Х, таке можливо лише тоді коли обидві частини рівняння є порожніми множинами, отже `X \ A = ∅, C \ X = ∅` => `X ⊆ A, C ⊆ X` => `C ⊆ X ⊆ A`
5. `A ∸ C = C \ A`, `A ⊆ C`
Відповідь: Нервінвність виконується за усіх множин А та С які задовольняють умову `A ⊆ C`
`(A ∩ C‾) ∪ (C ∩ A‾) = C ∩ A‾`, з цього рівняння ми бачимо що в лівій частині за означенням симетричної різниці та при умові `A ⊆ C` виключили з множини С усі елементи множини А. В правій частині ми бачимо абсолютно те саме, тобто рівняння виконується за усіх множин А та С які задовольняють умову `A ⊆ C`
6. `A \ (X \ C) = A ∪ C`
7. `(A \ X) \ C = A ∪ C`
8. `A ∸ X = C \ X`
9. `(A ∩ X) ∩ (C \ X) = A ∩ C`
