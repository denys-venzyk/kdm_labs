# Домашнє завдання 4. Множини: системи рівнянь  

**Тема:** Теорія множин  

## Завдання  

Розв'яжіть наступні системи рівнянь відносно `X` (кожна система складена з двох рівнянь ДЗ 3 — за потреби перевикористайте проміжні результати звідти):  

1. `{ A ∸ B = B ∸ X;  X \ A = C \ X }`  
Відповідь: `A = X` за умови `C ⊆ A`
Перше рівняння `A ∸ B = B ∸ X` має розв'язок `A = X`.  
Друге рівняння `X \ A = C \ X` має розв'язок `C ⊆ X ⊆ A`.  
З першого рівняння отримуємо `X = A`. Підставивши це у друге рівняння, маємо додаткову умову існування розв'язку `C ⊆ A`.
2. `{ A ∪ X = X \ B;  A \ (X \ C) = A ∪ C }`  
Відповідь: `X = A = C` за умов `A ∩ B = ∅` та `A = C`.
Перше рівняння `A ∪ X = X \ B` має розв'язок `A ⊆ X ⊆ B‾` за додаткової умови `A ∩ B = ∅`.  
Друге рівняння `A \ (X \ C) = A ∪ C` має розв'язок `X ⊆ C ⊆ A`.  
Друге рівняння дає `X ⊆ C` та `C ⊆ A`. Перше рівняння дає `A ⊆ X`. Звідси виникає `A ⊆ X ⊆ C ⊆ A`, що виконується лише тоді, коли `A = C`.  
3. `{ C \ B = (A ∪ B) \ X, A ⊆ C;  (A \ X) \ C = A ∪ C }`  
Відповідь: `X = B` за умов `A = ∅` та `C = ∅`.  
Перше рівняння `C \ B = (A ∪ B) \ X` за умови `A ⊆ C` має розв'язок `B ⊆ X ⊆ A ∪ B`.  
Друге рівняння `(A \ X) \ C = A ∪ C` має розв'язок лише за умови `C = ∅` та `A ∩ X = ∅`.  
З умовою першого рівняння `A ⊆ C` це дає `A = ∅`. Підставивши `A = ∅` у перше рівняння, отримуємо `B ⊆ X ⊆ ∅ ∪ B = B`, звідки `X = B`.  
4. `{ A ∸ C = C \ A, A ⊆ C;  A ∸ X = C \ X }`  
Відповідь: `A ∸ C ⊆ X ⊆ A` за умови `A ⊆ C`.  
Перше рівняння `A ∸ C = C \ A` за умови `A ⊆ C` виконується тотожно для будь-яких множин.  
Друге рівняння `A ∸ X = C \ X` має розв'язок `A ∸ C ⊆ X ⊆ A`.  
Додаткова умова для існування розв'язку всієї системи задана в першому рівнянні `A ⊆ C`. Межі для X визначаються другим рівнянням `A ∸ C ⊆ X ⊆ A`.  
5. `{ X \ A = C \ X;  (A ∩ X) ∩ (C \ X) = A ∩ C }`  
Відповідь: `X ⊆ A` за умови `A ∩ C = ∅`.  
Перше рівняння `X \ A = C \ X` має розв'язок `C ⊆ X ⊆ A`.  
Друге рівняння `(A ∩ X) ∩ (C \ X) = A ∩ C` має розв'язок лише за умови `A ∩ C = ∅`.  
З першого рівняння маємо `C ⊆ X ⊆ A`. Оскільки `C ⊆ A`, а з другого рівняння випливає, що `A ∩ C = ∅`, отже `C = ∅`. Підставивши `C = ∅`, отримуємо межі `∅ ⊆ X ⊆ A`.
